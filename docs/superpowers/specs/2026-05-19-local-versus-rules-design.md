# PVZ 本地双人对战规则设计

## 目标

把当前“植物防守 + director 自动刷僵尸”的原型改成真正的本地双人对战基础版：植物方负责种植和收集阳光，僵尸方负责手动选择僵尸并在右侧投放区投放。僵尸不再自动出现。

## 范围

- 本轮只做规则骨架，不新增单位和大型 UI。
- 保留 Canvas 渲染、命令队列、固定逻辑坐标、现有卡牌和投放区。
- 保留压力条，但它只表达僵尸方当前场面压力，不再触发自动波次。
- 保留背景音乐、音效、spritesheet 动画和当前素材映射。

## 规则

- 游戏开始后，植物方按原逻辑获得被动阳光、向日葵产阳光、收集阳光。
- 僵尸方按固定速率恢复脑力，用脑力手动投放僵尸。
- director 不创建 warning，不播放 wave 音效，不自动调用 `spawnZombie()`。
- 每次手动投放僵尸记录为一次 `manualDeployCount`，用于调试和浏览器验收。
- 压力值根据场上僵尸数量、生命值和突破距离平滑变化。
- 胜负逻辑保持：僵尸突破房子则僵尸方胜；时间结束且场上没有僵尸则植物方胜。

## 验收

- `updateGame()` 长时间推进不会自动产生僵尸。
- 手动投放僵尸会消耗脑力、增加 `manualDeployCount`、提高压力值。
- 初始未交互时计时器、资源和压力都不推进。
- 主浏览器流程不再要求自动波次数量。
- 现有动画、阳光、投放区和素材验证继续通过。
