# 玩法和表现升级迭代记录

## 设计目标

当前版本已经具备本地双人攻防骨架，但体验偏简单。此次迭代的目标是让游戏更像一局完整的塔防对战，而不是仅有单位碰撞的原型。

## 自主设计决策

- 增加可点击阳光掉落：把资源从纯数字变成玩家需要观察和操作的对象。
- 增加每路一次性割草机：允许植物方有一次失误缓冲，也让突破反馈更强。
- 增加导演波次：即使僵尸玩家暂时不操作，战场也会有预警、压力和自动进攻节奏。
- 增加战术单位：樱桃炸弹提供高冷却清场决策，小鬼僵尸提供低血高速骚扰。
- 增强 HUD：加入压力条、预警行、冷却倒计时、资源不足遮罩和更完整状态信息。
- 增强渲染：加入房屋侧、投放区、割草机、阴影、阳光、爆炸和波次预警效果。

## 实现计划

1. 扩展状态：`sunPickups`、`laneMowers`、`director`。
2. 扩展命令：`collectSun` 和复用 `spawnZombie`。
3. 扩展系统：阳光掉落、导演波次、割草机、冲刺计时、樱桃炸弹爆炸。
4. 扩展输入：优先点击阳光，再处理卡牌/格子/投放区。
5. 扩展渲染：新增阳光、割草机、威胁条、预警、爆炸和卡牌可用性反馈。
6. 扩展测试：覆盖阳光收集、导演波次、割草机、小鬼僵尸、樱桃炸弹。
7. 浏览器验证：跑真实点击流程，检查 `render_game_to_text()` 和截图。
